Sistem Informasi Pencalegan

Web application

A web-based information system for managing vote count data in legislative elections. It tracks and tabulates the votes cast at each polling station (TPS) accurately, and also manages data on party cadres and voters.

  • Role-based login: admin has full access and manages all data (CRUD); user can only input cadre and voter data.
  • Location-linked data: every cadre and voter record is tied to a sub-district and village, so the polling station (TPS) location can be traced.
  • Vote recap: voter data is summarized by sub-district or village, and totals are summed across the whole area.
  • Excel export: all stored data can be exported to Excel.

Sistem Informasi Pengelola Jimpitan (SIPETAN)

Web application

A web-based information system for managing jimpitan (community contribution) records in a neighborhood. It supports three user types (admin, officer, and residents) and gives the community one place to record contributions, share announcements, and handle complaints.

  • Role-based login: admin has access to all features; officer can add jimpitan records and submit complaints; residents can only submit complaints.
  • Information broadcast: admins create, edit, and delete announcements that appear on the dashboards of all user types.
  • Resident data: admins can view, add, edit, and delete resident records.
  • Jimpitan records: admins can view, add, edit, and delete entries, which are managed by officer accounts.
  • Complaints: complaints from officers and residents are collected on one page, where the admin addresses and resolves them.
  • User management: admins can view, add, edit, and delete user accounts.
  • PHP
  • HTML
  • CSS
  • JavaScript
  • CodeIgniter 3
  • Bootstrap
  • MySQL

Sistem Informasi Stock Opname (SINOP) Dishub

Web application

A web-based stock opname (inventory control) system for Dishub that tracks supplies across several categories. Recording incoming and outgoing items automatically updates the stock count, so the inventory data always reflects what is actually available.

  • Role-based login: admin has access to all features; guest can only record outgoing items.
  • Admin dashboard: shows the total inventory count currently recorded in the database.
  • Stock pages by category: office supplies (ATK), cleaning supplies, printed materials, and electrical items, each showing available stock with add, edit, and delete.
  • Incoming items: recording new stock acquisitions automatically increases the inventory count.
  • Outgoing items: recording item usage automatically decreases the inventory count.
  • User management: view, add, edit, and delete user records.
  • PHP Native
  • HTML
  • CSS
  • JavaScript
  • Bootstrap
  • MySQL
